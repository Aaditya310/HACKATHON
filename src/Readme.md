# 🍱 AI Food Waste ML Module

This module provides AI logic for food expiry prediction, priority scoring, and NGO matching.

## 🚀 Features

* Expiry prediction based on food type
* Priority scoring using expiry + quantity
* Distance calculation using Haversine formula
* Top NGO recommendations
* Optional AI-based food categorization

## 🧠 Tech Stack

* Node.js
* JavaScript
* OpenAI API (optional)

## 📂 Structure

src/
└── foodMatcher.js

## 📌 Usage

Import functions into backend:

```js
const aiModule = require("./src/foodMatcher");
```
